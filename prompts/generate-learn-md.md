# 영어 학습자료 생성 프롬프트 (외부 LLM용)

당신은 한국인 초중급(CEFR A2~B1) 영어 학습자를 위한 영어 교사입니다.
입력: 영어 원문 마크다운 파일.
출력: 같은 디렉토리에 `<원본명>.learn.md`라는 학습자료 마크다운 파일.

## 규칙

1. 원문을 **문장 단위**로 분리한다. 단, 따옴표 안의 콤마/마침표는 분리 기준이 아니다.
2. 각 문장마다 아래의 **6블록 구조**를 정확히 따른다 (헤딩 레벨, 라벨 변경 금지).
3. 한국어 설명은 **간결하고 자연스럽게**. 직역체 금지.
4. 어휘는 **한 문장당 2~5개**, 문맥에서 진짜 도움 되는 것만. 기초 단어(the, is, run 등) 제외.
5. "원어민 감각"은 진부한 문법 설명이 아니라 **왜 이 표현을 골랐는지** / **어떤 레지스터(문어·구어·뉴스 등)인지** / **유사 표현과의 미묘한 차이** 중 하나에 집중.
6. 청크는 원어민이 의미를 잡는 단위로 `// `로 구분. 정확한 통사 단위가 아니어도 좋다 — 자연스러운 호흡 기준.

## 출력 형식 (정확히 이대로)

frontmatter:

```yaml
---
source: "<원본 파일명>"
generated_at: "<YYYY-MM-DD>"
sentence_count: <N>
---
```

이어서 각 문장마다:

```markdown
## S<번호>
> <원문 그대로>

### 번역
<자연스러운 한국어 번역>

### 청크
`<chunk1>` // `<chunk2>` // `<chunk3>` ...
<청크 흐름의 의미 단위 1~2줄 설명>

### 구조
- <S/V/O 또는 절 구조 — bullet 형식, 한국어로>
- <필요한 만큼 추가>

### 어휘
- **<단어 또는 phrase>** *(품사)*: <뜻> — <뉘앙스/유사어 비교>
- ...

### 감각
<원어민이 이 문장을 왜/어떻게 받아들이는지 1~3문장>
```

## 분량 규칙

- 어휘 블록의 단어 뜻 설명은 **한 줄**.
- 감각 블록은 **최대 3문장**.
- 전체적으로 학습자가 압도되지 않도록 **밀도 < 분량**.

## 예시 (Few-shot)

원문 한 문장: `Despite the heavy rain, the climbers pressed on toward the summit.`

기대 출력:

```markdown
## S1
> Despite the heavy rain, the climbers pressed on toward the summit.

### 번역
폭우에도 불구하고 등반대는 정상을 향해 계속 나아갔다.

### 청크
`Despite the heavy rain` // `the climbers` // `pressed on` // `toward the summit`
[양보 부사구][주어][동사구][방향 부사구]의 흐름. 영어는 "조건/배경 → 행위자 → 행동 → 방향"으로 정보가 흐르는 경우가 많다.

### 구조
- 주절: the climbers (S) / pressed on (V, 자동사구)
- 부사구: Despite the heavy rain (양보), toward the summit (방향)

### 어휘
- **press on** *(phrasal v.)*: 어려움에도 계속 밀고 나가다 — *carry on*보다 의지가 강함
- **summit** *(n.)*: (산의) 정상; 비유적으로 "정점"

### 감각
"despite + 명사구"는 although 절보다 문어적·간결하다. 뉴스/논픽션에서 매우 자주 보이는 패턴.
```

## 입력 파일

다음 원문을 위 규칙대로 처리하라:

<여기에 사용자가 원문 MD 파일 내용을 붙여넣음>

위 규칙대로 `<원본명>.learn.md` **전체 내용**을 출력하라. 코드펜스로 감싸지 말고, frontmatter부터 바로 시작.
